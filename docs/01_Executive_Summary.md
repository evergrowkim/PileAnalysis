## 한 문장으로

---

## 핵심 가치 제안 (Value Proposition)

### Before (기존 방식)
- 엔지니어가 Excel과 CAD로 **수작업** 계산
- 시추공 1개당 **2~4시간** 소요
- 100개 시추공 프로젝트 = **200~400시간** (약 25~50 인일)
- 계산 오류 및 검토 누락 위험
- 설계 변경 시 전체 재계산 필요

### After (GeoAI 시스템)
- JSON 시추데이터 업로드 → **자동 계산 완료**
- 100개 시추공 = **30분 이내** 완료
- KDS/구조물기초설계기준 **100% 준수**
- 3D 공간 분석으로 **리스크 사전 식별**
- 설계변경 시 **즉시 재계산**

## 정량적 기대효과

| 항목 | 기존 | GeoAI 도입 후 | 개선율 |
|------|------|---------------|--------|
| 설계 소요시간 | 200~400시간 | 0.5시간 | **99.8% 단축** |
| 계산 오류율 | 5~10% | 0% (자동검증) | **100% 개선** |
| 설계변경 대응 | 3~5일 | 즉시 | **실시간** |
| 보고서 작성 | 1~2일 | 자동생성 | **100% 자동화** |

### 연간 비용 절감 효과 (추정)
- 프로젝트당 **500~1,000만원** 절감
- 연간 20개 프로젝트 기준 = **1~2억원** 절감
- 설계품질 향상으로 인한 **시공리스크 감소** (간접효과)

## 기술적 차별화

### 1. 국내 설계기준 완벽 준수
- **KDS 11 50 40** (깊은기초 설계기준)
- **구조물기초설계기준해설** (2015, 2018)
- **도로교설계기준** (2016)
- 시공방식별 공식 자동 적용 (타입/매입/현장타설)

### 2. 종합적 지지력 계산
- 연직 지지력 (주면마찰력 + 선단지지력)
- 수평 지지력 (Chang's Method + Broms' Method)
- 인발 저항력 (부력 고려)
- 침하량 계산 (Vesic 3성분 합산법)

### 3. 3D 공간 지반정보 분석
- 지층 경사 위험구간 자동 식별
- 근입 깊이 부족 말뚝 즉시 파악
- 말뚝장 분포 최적화 지원
- IDW 보간법 기반 지반 모델링

### 4. 설계 의사결정 지원 UI
- 핵심 질문 기반 인터페이스
- 실시간 설계 검토 알람
- 시추공별 상세 계산서 자동 생성
- 엔지니어 친화적 시각화
