## 1. 시추데이터 파싱 시스템

### 1.1 지원 포맷
- **JSON 형식** (GeoAI 표준)
- 다중 시추공 일괄 업로드
- 드래그 앤 드롭 지원

### 1.2 자동 인식 항목

| 항목 | 필드명 | 예시 |
|------|--------|------|
| 시추공 번호 | hole_no | BH-1, BH-2 |
| 지표고 | ORIGINAL_GROUND_ELEVATION | EL.52.30m |
| 지하수위 | GROUND_WATER_LEVEL | GL-3.50m |
| 좌표 (TM) | easting, northing | 197542.123 |
| 토층 정보 | soil_data[] | 매립층, 풍화암... |
| SPT N값 | Hits | 5/7/8, 50/30 |

### 1.3 데이터 정규화
```
원본 데이터                    정규화 후
─────────────────────────────────────────────
"EL.52.30m"            →      52.30 (숫자)
"GL-3.50m"             →      -3.50 (심도)
"5/7/8"                →      15 (합산 N값)
"50/30"                →      50 (N50 환산)
"197542.123"           →      42.12 (상대좌표)
```

### 1.4 검증 규칙
- 필수 필드 누락 검사
- 숫자 범위 유효성 검사
- 중복 시추공 번호 경고
- 좌표 유효성 검사

## 2. 입력 검토 모듈

### 2.1 프로젝트 기본 정보

**설정 가능 항목:**
- 계획고 (EL.m) - 성토/절토 자동 계산
- 지지층 선택 (풍화암/연암/경암)
- 근입 깊이 (m)

### 2.2 말뚝 규격 설정

#### PHC 말뚝 데이터베이스
| 규격 | 직경 | 두께 | 단면적 | 허용압축력 |
|------|------|------|--------|-----------|
| PHC-A 400 | 400mm | 65mm | 684cm² | 1,225kN |
| PHC-A 450 | 450mm | 70mm | 835cm² | 1,470kN |
| PHC-A 500 | 500mm | 80mm | 1,056cm² | 1,960kN |
| PHC-A 600 | 600mm | 90mm | 1,442cm² | 2,696kN |
| PHC-B/C | ... | ... | ... | ... |

#### 강관말뚝 설정
- 재질: STK400, STK490, SKK400, SKK490
- 직경: 자유 입력 (mm)
- 두께: 자유 입력 (mm)
- 허용압축력: 자동 계산

### 2.3 설계기준 선택

```
┌─────────────────────────────────────────────────────────────┐
│ 설계기준 선택                                               │
├─────────────────────────────────────────────────────────────┤
│ ○ 구조물기초설계기준해설 (2018)           ← 기본값         │
│   - 사질토: fs = 2.5N (≤125kPa)                            │
│   - 선단: qp = 200N (매입), 300N (타입)                    │
├─────────────────────────────────────────────────────────────┤
│ ○ 도로교설계기준 (2016)                                    │
│   - 사질토: fs = 5N (≤200kPa)                              │
│   - 선단: qp = 250N (일반)                                 │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 시공방법 선택

| 시공방법 | 설명 | 선단지지력 계수 |
|----------|------|-----------------|
| 매입말뚝 | SIP, SAIP, PRD | α = 200 |
| 타입말뚝 | 항타공법 | α = 300 |
| 현장타설 | 굴착 후 콘크리트 타설 | α = 150 |

### 2.5 침하량 계산 계수

#### 주면마찰력 분포계수 (αs)
- 균등분포: 0.5
- 삼각형분포: 0.67
- 포물선분포: 0.6

#### 경험계수 (Cp)
| 지반 | 타입말뚝 | 매입말뚝 |
|------|----------|----------|
| 모래 | 0.02~0.04 | 0.09~0.18 |
| 점토 | 0.02~0.03 | 0.03~0.06 |
| 실트 | 0.03~0.05 | 0.09~0.12 |

### 2.6 안전율 설정

| 항목 | 기호 | 기본값 | 범위 |
|------|------|--------|------|
| 압축 안전율 | FSc | 3.0 | 2.0~5.0 |
| 인발 안전율 | FSp | 3.0 | 2.5~5.0 |
| 수평 안전율 | FSh | 2.0 | 1.5~4.0 |

## 5. 상세 계산서

### 5.1 계산서 구성

```
┌─────────────────────────────────────────────────────────────┐
│                 말뚝 기초 상세 계산서                        │
│                 BH-1 | PHC-A 500mm                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 설계 조건                                               │
│  ───────────────────                                        │
│  • 설계기준: 구조물기초설계기준해설 (2018)                   │
│  • 시공방법: 매입말뚝 (SIP)                                 │
│  • 말뚝규격: PHC-A 500mm, t=80mm                           │
│  • 지표고: EL.52.30m                                        │
│  • 계획고: EL.50.00m (절토 2.3m)                           │
│                                                             │
│  2. 층별 주면마찰력                                         │
│  ───────────────────                                        │
│  ┌────────┬────────┬────────┬────────┬────────┐            │
│  │ 층명   │ 심도   │ 평균N  │ fs(kPa)│ Qs(kN) │            │
│  ├────────┼────────┼────────┼────────┼────────┤            │
│  │ 풍화토 │ 3~8m   │ 25     │ 62.5   │ 491    │            │
│  │ 풍화암 │ 8~12m  │ 50     │ 125    │ 785    │            │
│  ├────────┴────────┴────────┴────────┼────────┤            │
│  │                          합계 Qs  │ 1,276  │            │
│  └────────────────────────────────────┴────────┘            │
│                                                             │
│  3. 선단지지력                                              │
│  ───────────────────                                        │
│  • 선단 N값 (가중평균): N1=48, N2=52 → N=50                │
│  • 선단지지력도: qp = 200 × 50 = 10,000 kPa                │
│  • 상한값 적용: qp = 10,000 kPa (≤12,000 OK)               │
│  • 선단지지력: Qp = 10,000 × 0.196 = 1,963 kN              │
│                                                             │
│  4. 지지력 종합                                             │
│  ───────────────────                                        │
│  • 극한지지력: Qu = Qs + Qp = 1,276 + 1,963 = 3,239 kN     │
│  • 지반허용지지력: Qa = 3,239 / 3.0 = 1,080 kN             │
│  • 재료허용지지력: Qp = 1,960 kN (PHC-A 500 규격)          │
│  • 최종허용지지력: Qa = min(1,080, 1,960) = 1,080 kN       │
│                                                             │
│  5. 침하량 검토                                             │
│  ───────────────────                                        │
│  • Ss (말뚝압축): 3.2 mm                                   │
│  • Sp (선단침하): 1.8 mm                                   │
│  • Sps (주면침하): 0.5 mm                                  │
│  • 총침하량: St = 5.5 mm ≤ 25 mm → OK                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 출력 옵션

- **화면 표시**: 팝업 모달
- **이미지 저장**: PNG (고해상도)
- **PDF 출력**: 브라우저 인쇄 기능
