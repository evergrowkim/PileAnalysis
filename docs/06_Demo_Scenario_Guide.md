## 2. 라이브 데모 시나리오 (12분)

### 2.1 시나리오 개요

```
프로젝트: 가상 도로 건설 프로젝트
시추공 수: 20개
목표: 데이터 업로드부터 설계 완료까지 실시간 시연
```

### 2.2 스크립트

---

#### **Scene 1: 데이터 업로드 (1분)**

**화면**: index.html 초기 화면

**스크립트**:
> "이것이 GeoAI 시스템입니다. 보시다시피 웹 브라우저에서 바로 실행됩니다.
> 별도의 설치나 로그인이 필요 없습니다.
>
> 시추조사 데이터를 JSON 형태로 준비했습니다.
> 드래그 앤 드롭으로 업로드하겠습니다."

**액션**: JSON 파일을 업로드 영역에 드래그

**포인트**:
- 설치 불필요 강조
- 1초 만에 20개 시추공 파싱 완료
- 데이터 자동 검증 메시지

---

#### **Scene 2: 대시보드 확인 (2분)**

**화면**: 대시보드 탭

**스크립트**:
> "업로드 즉시 모든 시추공의 현황이 한눈에 보입니다.
>
> 지표고, 지하수위, 풍화암 심도, 연암 심도가 자동으로 추출되었습니다.
> 우측의 N값 추이 그래프는 각 시추공의 지반 특성을 시각적으로 보여줍니다.
>
> 검색과 정렬 기능으로 원하는 시추공을 빠르게 찾을 수 있습니다."

**액션**:
1. 테이블 스크롤하며 전체 현황 표시
2. 정렬 버튼 클릭 (풍화암 심도 기준)
3. 검색창에 "BH-10" 입력

**포인트**:
- 자동 데이터 추출 강조
- 시각적 N값 그래프
- 즉시 검색/정렬 기능

---

#### **Scene 3: 입력 검토 설정 (2분)**

**화면**: 입력 검토 탭

**스크립트**:
> "설계 조건을 설정하는 화면입니다.
>
> 말뚝 규격은 PHC-A 500mm를 선택하겠습니다.
> 시공방법은 매입말뚝, 지지층은 풍화암으로 설정합니다.
>
> 설계기준은 '구조물기초설계기준해설'을 선택하면,
> 해당 기준의 공식이 자동으로 표시됩니다.
>
> 사질토 주면마찰력 fs = 2.5N, 선단지지력 qp = 200N,
> 모두 자동으로 적용됩니다.
>
> '설정 적용' 버튼을 클릭하면 모든 시추공에 대한 계산이 시작됩니다."

**액션**:
1. 말뚝 규격 드롭다운에서 "PHC-A 500" 선택
2. 시공방법 "매입말뚝" 선택
3. 지지층 "풍화암" 선택
4. 설계기준 드롭다운 변경 시 공식 업데이트 확인
5. "설정 적용 및 계산 실행" 클릭

**포인트**:
- PHC 말뚝 규격 데이터베이스 내장
- 설계기준별 공식 자동 적용
- 일괄 계산 기능

---

#### **Scene 4: 계산 결과 확인 (2분)**

**화면**: 개요 탭 (종합 결과 테이블)

**스크립트**:
> "계산이 완료되었습니다. 1초도 채 안 걸렸습니다.
>
> 20개 시추공 모두에 대해:
> - 말뚝 길이
> - 선단 지지고
> - 허용 지지력
> - 침하량
> - 수평 지지력
> - 인발 저항력
>
> 이 모든 항목이 자동으로 계산되었습니다.
>
> 아래 통계 카드를 보시면,
> 평균 말뚝 길이 12.5m, 최소 허용지지력 1,050kN,
> 최대 침하량 8.2mm 등의 핵심 정보가 한눈에 보입니다."

**액션**:
1. 결과 테이블 스크롤
2. 통계 카드 하이라이트
3. 특정 시추공 행 클릭

**포인트**:
- 즉시 계산 완료
- 6가지 설계 항목 동시 산출
- 핵심 통계 자동 집계

---

#### **Scene 5: 시추주상도 시각화 (2분)**

**화면**: 시추주상도 탭

**스크립트**:
> "개별 시추공의 상세 현황을 시각적으로 확인할 수 있습니다.
>
> BH-5를 선택하겠습니다.
>
> 좌측에는 깊이별 EL 표시,
> 중앙에는 시추주상도와 토층 분포,
> 우측에는 N값 그래프와 누적 지지력 그래프가 표시됩니다.
>
> 말뚝은 반투명 박스로 표현되고,
> 선단 지지고가 빨간 점선으로 표시됩니다.
>
> 지지층인 풍화암에 근입된 것을 확인할 수 있습니다."

**액션**:
1. 시추공 드롭다운에서 "BH-5" 선택
2. 시각화 생성 확인
3. 말뚝 선단 위치 가리키기
4. N값 50 포인트 호버

**포인트**:
- 고품질 벡터 그래픽
- 직관적 토층 표현
- 말뚝-지지층 관계 명확

---

#### **Scene 6: 3D 공간 분석 (3분)** ⭐ 하이라이트

**화면**: 3D 지질모델 뷰어

**스크립트**:
> "이제 가장 핵심적인 기능을 보여드리겠습니다.
> '3D 지질 시각화' 버튼을 클릭합니다.
>
> [3D 모델 로딩]
>
> 모든 시추공의 공간적 위치와 지층 분포가
> 3D로 시각화되었습니다.
>
> 중요한 것은 단순한 3D가 아니라,
> 좌측 패널의 '설계 의사결정 지원' 정보입니다.
>
> 첫 번째: '지지층 경사가 급한 구간은?'
> BH-3과 BH-7 사이에 경사 12도로 고위험 구간이 식별되었습니다.
> 이 구간은 말뚝장 변화가 클 수 있어 주의가 필요합니다.
>
> 두 번째: '근입 깊이 부족 말뚝은?'
> BH-12가 기준 1.0m 대비 0.8m로 부족합니다.
> 설계 조정이 필요함을 바로 알 수 있습니다.
>
> 세 번째: 말뚝장 분포입니다.
> 최소 9.5m에서 최대 15.2m까지,
> 위치별 편차를 한눈에 파악할 수 있습니다.
>
> 시추공 마커를 클릭하면,
> 해당 위치를 중심으로 5m 반경이 확대되어
> 상세 분석이 가능합니다."

**액션**:
1. "3D 지질 시각화" 버튼 클릭
2. 3D 모델 회전 (마우스 드래그)
3. 좌측 설계 검토 패널 스크롤
4. 경사 위험 구간 하이라이트 확인
5. 특정 시추공 클릭 → 클리핑 뷰
6. 레이어 토글 (풍화암 ON/OFF)

**포인트**:
- 설계 의사결정 직결 정보
- 리스크 자동 식별
- 인터랙티브 분석

## 5. 예상 질문 및 답변

### 5.1 기술 관련 질문

**Q1: 계산 결과의 정확도는 어떻게 검증했나요?**
> "기존 Excel 계산 결과와 100% 일치하도록 검증했습니다.
> 또한, 설계기준에 명시된 예제 문제를 풀어 공식 적용의 정확성을 확인했습니다.
> 실제 프로젝트에서 감리 검토도 모두 통과했습니다."

**Q2: 설계기준이 개정되면 어떻게 대응하나요?**
> "시스템 내부에 설계기준별 공식이 상수로 정의되어 있습니다.
> 기준 개정 시 해당 상수만 업데이트하면 전체 시스템에 즉시 반영됩니다.
> 코드 수정 후 배포까지 1~2일이면 충분합니다."

**Q3: 특수한 지반 조건에도 적용 가능한가요?**
> "현재는 일반적인 토사 및 풍화암/연암 지반에 최적화되어 있습니다.
> 특수 조건(액상화, 연약지반 등)에 대한 기능은 향후 확장 계획에 포함되어 있습니다.
> 사용자 정의 계수 기능을 통해 일부 대응도 가능합니다."

### 5.2 비즈니스 관련 질문

**Q4: 도입 시 교육은 얼마나 필요한가요?**
> "기본 사용법은 30분이면 충분합니다.
> 직관적인 UI로 설계되어 별도의 교육 없이도 사용 가능합니다.
> 상세 기능은 온라인 매뉴얼과 동영상을 제공할 예정입니다."

**Q5: 외부 판매나 라이선스 가능성은?**
> "현재는 내부 사용에 초점을 맞추고 있습니다.
