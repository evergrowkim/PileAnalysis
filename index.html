상세 계산 과정 (시추공: NBH-1)

Step 1. 말뚝 길이 결정
1-1
변수 정의:
• $EL_{start}$ : 말뚝 두부 표고 (작업면 표고)
• $EL_{tip}$ : 말뚝 선단 표고 (지지층 근입 후)
• $L_{pile}$ : 말뚝 전체 길이 (m)
$$L_{pile} = EL_{start} - EL_{tip}$$
작업면 표고: $EL_{start} = 133.4$ m
지지층 상단: $EL_{bearing} = 119.9$ m (풍화암층)
근입 깊이: $P_{penetration} = 1.0$ m (구조물 기초 설계 기준 규정)
$L_{pile} = 133.4 - 119.9 + 1.0 = 14.5$ m
Step 2. 연직 지지력 계산
2-1
사질토 (βs=2.0) 점성토 (βc=6.25)
토층명 깊이
(EL, m)		 토질분류 말뚝길이
(m)		 N값 β
(kPa)		 $f_s$
(kPa)		 $A_s$
(m²)		 $Q_s$
(kN)		 누적
(kN)
총 주면마찰력: $Q_s = 485.3$ kN
2-2
선단지지력 계산: $$q_p = C_{end} \times N_{tip}$$
지지층 N값: $N_{tip} = 50$ (풍화암)
선단 단면적: $A_p = \frac{\pi \times D^2}{4} = \frac{\pi \times (0.5)^2}{4} = 0.196$ m²
$q_p = 300 \times 50 = 15,000$ kPa → 상한값 15,000 kPa 적용
$Q_p = q_p \times A_p = 15,000 \times 0.196 = 2,940$ kN
2-3
극한지지력 산정:
$$Q_u = Q_s + Q_p$$
주면마찰력 + 선단지지력
극한지지력: $Q_u = Q_s + Q_p = 485.3 + 2,940 = 3,425.3$ kN
2-4
지반 허용지지력 산정:
$$Q_{a,soil} = \frac{Q_u}{FS_v}$$
극한지지력을 안전율로 나눈 값
지반 허용지지력: $Q_{a,soil} = \frac{Q_u}{FS_v} = \frac{3,425.3}{3.0} = 1,141.8$ kN
2-5
허용지지력 결정:
$$Q_a = \min\left(Q_{a,soil}, Q_{a,material}\right)$$
지반 허용지지력과 재료 허용지지력 중 작은 값 적용
재료 허용지지력: $Q_{a,material} = 1,780$ kN (PHC 500-B)
이음 방법 적용:
이음 없음: $Q_{a,material} = 1,780$ kN (감소 없음)
최종 허용지지력: $Q_a = \min(1,141.8, 1,780) = 1,141.8$ kN
Step 3. 침하량 분석
3-1
3성분 합산법 (Vesic 방법):
• $S_s$ : 말뚝 자체 탄성압축 (mm)
• $S_p$ : 선단 하부 지반 침하 (mm)
• $S_{ps}$ : 주면마찰력에 의한 침하 (mm)
• $S_c$ : 압밀침하 (mm) - 암반지지시 무시
총 침하량: $$S_{total} = S_s + S_p + S_{ps} + S_c$$
3-2
말뚝 탄성압축 ($S_s$) 공식:
$$S_s = \frac{(Q_{ps} + \alpha_s \cdot Q_{fs}) \times L}{A_p \times E_p}$$
• $Q_{ps}$ = 선단 전달 하중 (kN)
• $Q_{fs}$ = 주면 전달 하중 (kN)
• $\alpha_s$ = 0.67 (삼각형 분포 가정)
• $A_p$ = 말뚝 단면적 (m²)
• $E_p$ = 말뚝 탄성계수 (kPa)
탄성계수 기준 (구조물 기초 설계기준 해설 표 5.3.10)
• PC/PHC 말뚝: $E_p = 3.92 \times 10^7$ kN/m² = 39,200 MPa
• 강관말뚝: $E_p = 2.00 \times 10^8$ kN/m² = 200,000 MPa
• 현장타설 콘크리트: $E_p = 2.45 \times 10^7$ kN/m² = 24,500 MPa
허용지지력: $Q_a = 800$ kN
선단/주면 분담비: $Q_{ps}$ : $Q_{fs}$ = 기반 산정
말뚝 길이: $L = 14.5$ m
단면적: $A_p = 0.1056$ m² (PHC 500mm)
탄성계수: $E_p = 39,200$ MPa (PHC 말뚝, 표 5.3.10)
$S_s = \frac{(Q_{ps} + 0.67 \times Q_{fs}) \times L}{A_p \times E_p} = 2.8$ mm
3-3
선단 하부 지반 침하 ($S_p$) 공식:
$$S_p = \frac{C_p \times Q_{ps}}{D \times q_p}$$
• $C_p$ = 경험계수 (매입말뚝-사질토: 0.12 권장)
• $D$ = 말뚝 직경 (m)
• $q_p$ = 극한 선단지지력도 (kPa)
선단 전달 하중: $Q_{ps} = Q_a \times (Q_p/Q_u)$ kN
경험계수: $C_p = 0.12$ (매입말뚝, 사질토 권장값)
말뚝 직경: $D = 0.5$ m
$S_p = \frac{C_p \times Q_{ps}}{D \times q_p} \times 1000 = $ mm
3-4
주면마찰력에 의한 침하 ($S_{ps}$) - Vesic 변형식:
$$S_{ps} = \frac{Q_{fs} \times C_s}{L \times q_p}$$
$$C_s = \left(0.93 + 0.16\sqrt{\frac{L}{D}}\right) \times C_p$$
주면 전달 하중: $Q_{fs} = Q_a \times (Q_s/Q_u)$ kN
$C_s = (0.93 + 0.16\sqrt{L/D}) \times C_p$
$S_{ps} = \frac{Q_{fs} \times C_s}{L \times q_p} \times 1000 = $ mm
3-5
총 침하량 산정:
$S_{total} = S_s + S_p + S_{ps} + S_c$
$S_{total} = 2.8 + 10.5 + 3.4 + 0 = 16.7$ mm

총 침하량 16.7 mm ≤ 허용침하량 25 mm ∴ 적합 (PASS)
Step 4. 수평 지지력 계산
4-1
수평지반반력계수 ($k_h$) 산정:
• 점성토 (후쿠오카식): $k_h = 6,910 \times N^{0.406}$ (kN/m³)
• 사질토 (요코야마식): $k_h = 2,000 \times N$ (kN/m³)
• 상부 5m 구간 평균 N값 기반
• 최소값: $k_{h,min} = 10,000$ kN/m³
지반반력계수: $k_h = 30,000$ kN/m³ (지반 조건 기반 산정)
4-2
Chang's Method (변위 기준):
특성계수: $\beta = \sqrt[4]{\frac{k_h \times D}{4 \times E \times I}}$ (m⁻¹)
장말뚝 판정: $\beta L > 2.5$ (장말뚝), $\beta L \leq 2.5$ (단말뚝)
허용 수평지지력: $H_{a,Chang} = \frac{2\sqrt{EI \cdot k_h \cdot D} \cdot Y}{FS_h}$ (kN)
단면2차모멘트: $I = \frac{\pi}{64}(D^4 - d^4)$ m⁴, 휨강성: $EI$ kN·m²
$\beta = \sqrt[4]{\frac{k_h \times D}{4 \times EI}} = $ m⁻¹
$\beta L = \beta \times L > 2.5$ ∴ 장말뚝
4-3
Broms' Method (파괴 기준):
항복모멘트: $M_y = Z_p \times \sigma_y$ (kN·m)
$\quad Z_p = \frac{4}{3}(R^3 - r^3)$ - 플라스틱 단면계수
극한지지력 (장말뚝, 사질토):
$\quad H_u = \frac{9 M_y}{\gamma \times D^3 \times K_p}$ (kN)
허용 수평지지력: $H_{a,Broms} = \frac{H_u}{FS_h}$ (kN)
4-4
[최종 결과]
$H_a = \min(H_{a,Chang}, H_{a,Broms})$ (변위기준과 파괴기준 중 작은 값)
Step 5. 인발 저항력 계산
5-1
인발 저항력 기본 공식:
$$Q_{pull} = \frac{Q_u}{FS_p} + W_p$$
• $Q_u$ = 극한 인발저항력 (kN) = $Q_s \times 0.8$ (저감계수 적용)
• $FS_p$ = 인발 안전율 (3.0)
• $W_p$ = 유효 자중 (kN) - 부력 고려
※ 인발 시 선단지지력 기여 없음, 주면마찰력은 압축의 80% 적용
5-2
구간 길이 산정 (부력 계산용):
• $l_1$ = 공기중 말뚝 길이 (지하수위 상부)
• $l_2$ = 수중 말뚝 길이 (지하수위 하부)
지하수위: $EL_{GWL} = $ - m
공기중 길이: $l_1 = L - l_2 = $ - m
수중 길이: $l_2 = EL_{GWL} - EL_{tip} = $ - m
5-3
유효 자중 ($W_p$) 산정:
$$W_p = W_{total} - B$$ $$W_{total} = w_{pile} \times L$$ $$B = A_p \times l_2 \times \gamma_w$$
기호 설명:
$W_p$ 유효 자중 (kN)
$W_{total}$ 전체 자중 (kN)
$w_{pile}$ 말뚝 단위중량 (kN/m)
$L$ 말뚝 길이 (m)
$B$ 부력 (kN)
$A_p$ 말뚝 단면적 (m²)
$l_2$ 수중 말뚝 길이 (m)
$\gamma_w$ 물의 단위중량 = 10 kN/m³
전체 자중: $W_{total} = w_{pile} \times L = $ - kN
부력: $B = A_p \times l_2 \times \gamma_w = $ - kN
유효 자중: $W_p = W_{total} - B = $ - kN
5-4
허용 인발 저항력:
$Q_{pull} = \frac{Q_u}{FS_p} + W_p = \frac{Q_s \times 0.8}{3.0} + W_p = $ - kN

C. 적용된 지반 관련 공식

C-1. 연직 지지력 계산

1) 허용지지력 기본식

$$R_a = \frac{1}{F_s}(R_p + R_f) - W_e$$

여기서, $R_p$ = 극한 선단지지력, $R_f$ = 극한 주면마찰력, $F_s$ = 안전율 (3.0), $W_e$ = 유효 자중

2) 주면마찰력 (Rf)

$$R_f = \sum_{i=1}^{n} (f_{si} \times A_{si})$$

여기서, $f_{si}$ = 주면마찰응력 (kN/m²), $A_{si}$ = 주면면적 (m²)

주면마찰응력 (fs) 산정:

점성토 (α법 - Tomlinson):

$c_u = 12 \times N$ (kN/m²)

$\alpha = \begin{cases} 1.0 & (c_u < 25) \\ 0.9 & (25 \leq c_u < 50) \\ 0.7 & (50 \leq c_u < 100) \\ 0.5 & (c_u \geq 100) \end{cases}$

$f_s = \min(\alpha \times c_u, 150)$ (kN/m², 상한 150)

사질토:

$f_s = \min(2 \times N, 200)$ (kN/m², 상한 200)

3) 선단지지력 (Rp)

$$R_p = q_p \times A_p$$

타입말뚝: $q_p = \min(300 \times N, 15,000)$ (kN/m²)

매입말뚝: $q_p = \min(200 \times N, 12,000)$ (kN/m²)

$$A_p = \frac{\pi \times D^2}{4}$$ (m²)

여기서, $N$ = 선단부 상부 1D~하부 4D 구간 평균 N값 (최대 60)

4) 허용지지력

$$Q_a = \min\left(\frac{Q_u}{FS_v}, Q_{a,material}\right)$$

여기서, $FS_v$ = 연직 안전율 (3.0), $Q_{a,material}$ = 재료 허용지지력

※ 시공방법에 따른 보정: 타입말뚝 = 1.0, 매입말뚝 = 0.7

C-2. 침하량 계산

총 침하량

$$S_{total} = S_s + S_p + S_{ps} + S_c$$

1) 말뚝 탄성압축 (Ss)

$$S_s = \frac{(Q_{ps} + \alpha_s \cdot Q_{fs}) \times L}{A_p \times E_p}$$ (m → mm 변환)

$\alpha_s = 0.67$ (삼각형 분포 가정)

여기서, $Q_{ps}$ = 선단 전달 하중, $Q_{fs}$ = 주면 전달 하중

PHC 말뚝: $E_p = 40,000,000$ kPa (40,000 MPa)

강관 말뚝: $E_p = 205,000,000$ kPa (205,000 MPa)

2) 선단 하부 지반 침하 (Sp)

$$S_p = \frac{C_p \times Q_{ps}}{D \times q_p}$$ (m → mm 변환)

$C_p$ = 경험계수

타입말뚝 (사질토)0.02 ~ 0.04
매입말뚝 (사질토)0.09 ~ 0.18 (권장 0.12)
매입말뚝 (풍화암)0.09

3) 주면마찰력에 의한 침하 (Sps) - Vesic 변형식

$$S_{ps} = \frac{Q_{fs} \times C_s}{L \times q_p}$$ (m → mm 변환)

$$C_s = (0.93 + 0.16\sqrt{L/D}) \times C_p$$

4) 압밀침하 (Sc)

$$S_c = 0$$ (암반 지지층의 경우)

※ 허용침하량: 교량 25mm, 일반건물 25~50mm, 발전소/정밀기초 15~20mm

C-3. 수평 지지력 계산

1) 수평지반반력계수 (kh) 산정

지반변형계수 (E₀):

일반토사 (N < 30): $E_0 = 700 \times N$ (kN/m²)

풍화암/조밀토 (N ≥ 30): $E_0 = 2,800 \times N$ (kN/m²)

수평지반반력계수:

점성토 (후쿠오카식): $k_h = 6,910 \times N^{0.406}$ (kN/m³)

사질토 (요코야마식): $k_h = 2,000 \times N$ (kN/m³)

최소값: $k_{h,min} = 10,000$ kN/m³

※ 상부 5m 구간의 평균 N값을 기반으로 자동 산정됩니다.

2) Chang's Method (변위 기준)

특성계수: $$\beta = \sqrt[4]{\frac{k_h \times D}{4 \times E \times I}}$$ (m⁻¹)

장말뚝 판정: $\beta L > 2.5$ (장말뚝), $\beta L \leq 2.5$ (단말뚝)

허용 수평지지력: $$H_{a,Chang} = \frac{2\sqrt{EI \cdot k_h \cdot D} \cdot Y}{FS_h}$$ (kN)

여기서, $Y$ = 허용변위 (영구 15mm, 가설 25mm), $FS_h$ = 수평 안전율 (2.0)

3) Broms' Method (파괴 기준)

항복모멘트: $M_y = Z_p \times \sigma_y$ (kN·m)

플라스틱 단면계수: $Z_p = \frac{4}{3} \times (R^3 - r^3)$ (m³)

여기서, $R = D/2$ (외반경), $r = d/2$ (내반경), $d = D - 2t$

극한 수평지지력: $$H_u = \frac{9 M_y}{\gamma \times D^3 \times K_p}$$ (kN)

허용 수평지지력: $$H_{a,Broms} = \frac{H_u}{FS_h}$$ (kN)

여기서, $\gamma$ = 토질 단위중량 (18 kN/m³), $K_p = \tan^2(45 + \phi/2) \approx 3$ (φ=30°)

4) 최종 허용 수평지지력

$$H_a = \min(H_{a,Chang}, H_{a,Broms})$$

※ 변위기준(Chang)과 파괴기준(Broms) 중 작은 값을 보수적으로 적용합니다.

C-4. 인발 저항력 계산

기본 공식

$$Q_{pull} = \frac{Q_u}{FS_p} + W_p$$ (kN)

1) 인발 극한저항력 (Qu)

$$Q_u = Q_s \times 0.8$$ (저감계수 적용)

※ 인발 시 주면마찰력은 압축의 80% 적용 (선단지지력 기여 없음)

사질토: $f_s = 1.6 \times N$ (상한 120 kN/m²)

점성토: $f_s = 4.0 \times N$ 또는 $0.64 \times c_u$ (상한 120 kN/m²)

2) 유효 자중 (Wp) 산정

전체 자중: $W_{total} = w_{pile} \times L$ (kN)

부력: $B = A_p \times l_{sub} \times \gamma_w$ (kN)

유효 자중: $W_p = W_{total} - B$ (kN)

여기서, $l_{sub}$ = 지하수위 아래 말뚝 길이 (m), $\gamma_w$ = 10 kN/m³

3) 안전율

$FS_p$ = 3.0 (정역학적 공식 기준)

※ 인발 저항력은 저감된 주면마찰력에 안전율을 적용한 후 유효 자중을 더하여 산정합니다.

N60 보정이란?

표준관입시험(SPT)에서 측정된 N값을 60% 해머효율 기준으로 보정하는 것입니다.
다양한 장비와 방법으로 측정된 N값을 일관된 기준으로 비교할 수 있게 합니다.

계산식
\( N_{60} = N \times \frac{E_m}{60} \)

여기서 \( E_m \)은 실제 해머효율(%), N은 측정된 N값입니다.
